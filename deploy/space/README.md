# ohmwork

A digital-logic lab question in plain English goes in. A Logisim circuit file
and its truth table come out — and the table was computed by Logisim
Evolution evaluating that exact file, not by the language model that designed
it.

If the evaluator disagrees with the specification, the design is thrown away
and redone. Nothing is returned unverified.

Source, and the engineering notes behind it:
**https://github.com/ShaanGS/ohmwork**

This Space is deployed from that repository; the README you are reading is the
deployment's own, replaced at push time so the Space carries the metadata
Hugging Face needs.
