Built so a wrong answer is harder than no answer

Everything below is something the app actually does, not a promise.

Chips are measured, not remembered

Name a 7447 and Ohmwork probes a real one in the evaluator first, all 128 input rows, then checks your design against that. Nobody's memory of a datasheet is involved.

Built on one rule

The model never grades its own work.

Nothing reaches you unless an outside tool agreed

The model writes the circuit. Logisim Evolution or LTspice runs the emitted file. If the tool disagrees, the design is thrown away and the tool's objection goes back to the model. If nothing passes, you get an honest failure.

Four outcomes, four looks, never confused

The simulator can't read your question. You can.

A simulator proves the circuit matches the reading. It can't prove the reading matches the question: an enable read as active-low when the manual meant active-high passes every check. So the reading is printed first, every time.
